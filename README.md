# Веб-приложение для учета личных финансов

Проект описывает продукт, который анализирует поведение пользователя, помогает планировать бюджет и визуализирует расходы. Основная цель — предоставить понятный интерфейс, аналитические инсайты и безопасный обмен данными через REST API с JWT авторизацией.

## Основные функции
- Регистрация и вход с **JWT авторизацией**.
- Управление счетами, категориями и операциями.
- Прогнозирование трат по поведенческим паттернам.
- Уведомления о достижении/превышении целей и гибкая настройка бюджета.
- Экспорт и импорт данных.
- Воронки расходов и доходов на интерактивных графиках.

## Архитектура и дизайн
- **Методология проектирования**: сочетаем C4-модель (контекст → контейнеры → компоненты), UML-диаграммы последовательностей для ключевых потоков и ER-диаграммы для согласования схемы PostgreSQL.
- **C4 уровни**:
  - Система: веб-приложение личных финансов.
  - Контейнеры: frontend (React/TypeScript/Material-UI), backend (FastAPI/Uvicorn), база данных (PostgreSQL), сервис фоновых задач.
  - Компоненты: аутентификация, управление транзакциями, аналитика поведения, уведомления.
- **Безопасность**: JWT хранится в httpOnly cookie или в памяти клиента; бэкенд валидирует токены на каждом запросе к REST API.

## Стек технологий
### Frontend
- **TypeScript**.
- **React** c **Material-UI** для сборки интерфейсов.
- **Chart.js** для построения диаграмм и дашбордов.

### Backend
- **Python**.
- **FastAPI** (REST API) под управлением **Uvicorn**.

### База данных
- **PostgreSQL** с миграциями (например, Alembic) и индексами под аналитические запросы.

## API и безопасность
- REST API со слоями сервисов и схемами Pydantic для валидации данных.
- JWT авторизация с ролями (пользователь, администратор) и refresh endpoint для обновления токена.
- Лимитирование запросов, аудит действий и мониторинг.

## Поведенческая аналитика
- Сбор событий (создание транзакций, изменение категорий, установка целей).
- Модели склонности к перерасходу и рекомендации по бюджету.
- Прогнозы и инсайты в диаграммах Chart.js.

## Развертывание
- Контейнеризация сервисов: `frontend` (статические файлы), `backend` (Uvicorn), `db` (PostgreSQL).
- В продакшене включаются HTTPS, логирование, метрики и алерты.
