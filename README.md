# Разработка веб-приложения для учета личных финансов

Проект описывает веб-приложение, которое анализирует поведение пользователя, помогает планировать бюджет и визуализирует расходы. Решение строится на современном стеке и предполагает дальнейшее расширение.

## Основные функции
- Регистрация и вход с **JWT авторизацией**.
- Управление счетами, категориями и операциями.
- Прогнозирование трат на основе истории и поведенческих паттернов.
- Настраиваемые уведомления и цели.
- Экспорт и импорт данных.
- Визуализация воронок расходов и доходов через интерактивные графики.

## Архитектура и дизайн
- **Методология проектирования**: рекомендуется сочетать C4-модель для макроархитектуры, UML-диаграммы последовательностей для ключевых потоков и ER-диаграммы для согласования схемы PostgreSQL.
- **C4 уровни**: 
  - Система: веб-приложение личных финансов.
  - Контейнеры: frontend, backend (FastAPI), база данных (PostgreSQL), сервис фоновых задач.
  - Компоненты: модули аутентификации, управления транзакциями, аналитики и уведомлений.
- **Безопасность**: JWT хранится в httpOnly cookie или в памяти клиента; бэкенд проверяет токены в каждом запросе к REST API.

## Стек технологий
### Frontend
- **TypeScript**
- **React** с **Material-UI** для быстрой сборки интерфейсов
- **Chart.js** для построения диаграмм и дашбордов

### Backend
- **Python**
- **FastAPI** (REST API) под управлением **Uvicorn**

### База данных
- **PostgreSQL** с миграциями (например, Alembic) и индексами под аналитические запросы

## API и безопасность
- REST API со слоями сервисов и схемами pydantic для валидации.
- JWT авторизация с ролями (пользователь, администратор); обновление токена через refresh endpoint.
- Лимитирование запросов и аудит действий.

## Поведенческая аналитика
- Сбор событий (создание транзакций, изменение категорий, установка целей).
- Построение моделей склонности к перерасходу и рекомендаций по бюджету.
- Отображение прогнозов и инсайтов в Chart.js графиках.

## Развертывание
- Контейнеризация сервисов; процесс: `frontend` → статические файлы, `backend` → Uvicorn, `db` → PostgreSQL.
- В продакшене включается HTTPS, мониторинг, сбор логов и метрик.

## Дорожная карта
1. Подготовить ER-диаграмму и миграции PostgreSQL для операций и категорий.
2. Реализовать REST API FastAPI с JWT авторизацией и тестами.
3. Создать React UI на TypeScript с Material-UI и дашбордом на Chart.js.
4. Настроить CI/CD и контейнеризацию.
